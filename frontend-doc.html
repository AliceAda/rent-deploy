项目概览 Overview

技术栈 Vue 3 + TypeScript

Vue 3 Composition API + TypeScript 5.x，支持可选链、空值合并等现代语法

UI框架 Element Plus

基于 Element Plus 2.x，支持暗黑模式、主题定制、国际化

状态管理 Pinia

Pinia 2.x 状态管理，支持多 store 隔离，DevTools 调试友好

路由管理 Vue Router 4

Vue Router 4 路由守卫，支持 RBAC 权限控制和动态路由

构建工具 Vite 5

Vite 5 快速构建，支持 HMR、代码分割、Tree Shaking

图表库 ECharts 5

ECharts 5 数据可视化，支持动态数据绑定和响应式图表

部署指南 Deploy

🚀 开发环境启动

# 安装依赖 npm install # 启动开发服务器 npm run dev # 访问地址 http://localhost:5173 # 类型检查 npm run type-check

📦 生产构建

# 构建生产版本 npm run build # 预览生产版本 npm run preview # 代码检查 npm run lint

🐳 Docker 部署

# 构建镜像 docker build -t anju-rent-frontend . # 运行容器 docker run -d -p 80:80 anju-rent-frontend
✅ 部署检查清单
  • 环境变量配置 (.env.production)
  • API 代理配置 (vite.config.ts)
  • Nginx 静态资源部署
  • HTTPS 证书配置
  • 错误监控接入 (Sentry)
  • 性能监控 (Google Analytics)

开发规范 规范

📁 文件命名

Vue 组件使用 PascalCase，工具函数使用 camelCase，API 模块使用小写

🏷️ 注释规范

组件添加 JSDoc 注释，复杂逻辑添加行内注释，导出接口添加说明

🔐 安全规范

敏感信息不硬编码，API 请求添加 Token，用户输入进行校验

⚡ 性能优化

路由懒加载，组件按需引入，图片压缩，虚拟列表优化
