项目概览 Overview

技术栈 Vue 3 + TypeScript

使用 Vue 3 Composition API + TypeScript 开发，类型安全，开发体验佳 (Vue ^3.4.21 / TS ^5.4.5)

UI框架 Element Plus

基于 Element Plus 组件库 (^2.9.0)，提供丰富的管理后台组件，图标使用 @element-plus/icons-vue

状态管理 Pinia

使用 Pinia (^2.1.7) 进行状态管理，支持多角色状态隔离

路由管理 Vue Router 4

基于角色的路由守卫，支持 RBAC 权限控制 (vue-router ^4.3.0)

图表 ECharts

使用 ECharts (^5.6.0) 实现租金趋势、对比雷达、数据大屏等可视化

开发规范 规范

📁 文件命名

Vue 组件使用 PascalCase，工具函数使用 camelCase，API 模块使用小写

🏷️ 注释规范

组件添加 JSDoc 注释，复杂逻辑添加行内注释，导出接口添加说明

🔐 安全规范

敏感信息不硬编码，API 请求添加 Token，用户输入进行校验

⚡ 性能优化

路由懒加载，组件按需引入，图片压缩，虚拟列表优化
